# 🎙️ Boombox Portfolio

ラジカセをモチーフにした、音楽再生機能付きのポートフォリオサイトです。

## 概要

Chill風なラジカセのUIで、自分のお気に入りな制作物を音楽付きで紹介できるポートフォリオサイトです。曲を切り替えると、対応する制作物の情報が表示されます。

## デモ

🔗 [デモを見る](https://boombox-app.vercel.app/)

## 主な機能

- 音楽の再生・停止
- 前の曲・次の曲への切り替え
- 曲に連動した制作物情報の表示（プロジェクト名・説明・デモリンク）
- 再生中にリールが回転するアニメーション
- 曲名のスクロール表示

## 使用技術

- React
- TypeScript
- Vite
- CSS

## 動かし方

```bash
# 依存パッケージをインストール
npm install

# 開発サーバーを起動
npm run dev
```

起動後、ターミナルに表示される `http://localhost:5173` をブラウザで開くと使えます。
