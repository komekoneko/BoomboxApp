# 🎙️ Boombox Portfolio

ラジカセをモチーフにした、音楽プレイヤー型のポートフォリオサイトです。

## 概要

チルな雰囲気のラジカセUIで、実際に音楽を再生しながら自己紹介と制作物を紹介できるポートフォリオサイトです。曲を切り替えると、対応するコンテンツが表示されます。

## デモ

🔗 [デモを見る](https://boombox-app.vercel.app/)

## 主な機能

**プレイヤー機能**

- 音楽の再生・停止
- 前の曲・次の曲への切り替え
- 曲が終わったら自動で次の曲へ
- シークバー（再生位置の表示・頭出し・再生時間表示）
- 音量調整
- トラックリストから任意の曲へ直接切り替え

**コンテンツ**

- 自己紹介トラック
- 制作物3件（プロジェクト名・説明・デモリンク）

**演出**

- 再生中のみ回転するカセットリール
- 再生中のみ流れる曲名スクロール
- 再生中のみ揺れるノイズテクスチャ
- 常時ゆっくり漂う背景グラデーション
- スキャンライン（走査線）
- スマートフォン対応（レスポンシブ）

## 工夫した点

**状態管理とコンポーネント設計**

再生状態・現在のトラック・音量・再生位置を `App.tsx` に集約し、表示を担う `Boombox` / `TrackList` / `Content` へ props で受け渡す構成にしました。子コンポーネントは表示と操作の通知に専念させています。

**音声制御**

`useRef` で audio 要素を保持し、`useEffect` 内で `ended` / `timeupdate` / `loadedmetadata` の各イベントを購読。クリーンアップ関数でイベントリスナーを解除し、登録が重複しないようにしています。

**演出と状態の連動**

リールの回転・曲名スクロール・ノイズは、再生中のみ動くよう state に応じて CSS クラスを切り替えています。停止中に演出だけが動き続ける違和感を避けました。

## ディレクトリ構成

```
src/
├── App.tsx              # 状態管理とロジック
├── App.css
├── data/
│   └── track.ts         # トラックデータと型定義
└── component/
    ├── Boombox.tsx      # ラジカセ本体（再生操作・シーク・音量）
    ├── TrackList.tsx    # トラック一覧
    └── Content.tsx      # 制作物・自己紹介の詳細
```

## 動かし方

```bash
# 依存パッケージをインストール
npm install

# 開発サーバーを起動
npm run dev
```

起動後、ターミナルに表示される `http://localhost:5173` をブラウザで開くと使えます。
